# NeuroCommenter

Софт для автокомментирования постов в Telegram-каналах через **user-аккаунт** + бесплатные нейронки + ротация прокси. Заточен под персону "владелец онлайн-школы программирования для детей" (промпт можно сменить).

## Что умеет

- Подключается к твоему Telegram через User API (Telethon, не бот)
- Подтягивает список каналов на которые ты подписан
- Ты галочками отмечаешь те, в которых хочешь оставлять комменты
- Слушает новые посты в этих каналах
- Через рандомную задержку (по умолчанию 3–30 мин) генерит контекстный коммент через LLM и постит его в обсуждение под постом
- Ротация AI-провайдеров: **Groq → OpenRouter → Cerebras → SambaNova → Mistral**
- Ротация прокси (socks5/http) для AI-запросов
- Веб-панель на `http://127.0.0.1:8800`
- Режим ручного аппрува комментов (включается переключателем)

## Установка

```bash
cd NeuroCommenter
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

Открой `.env` и заполни:

### 1. Telegram User API (обязательно)
1. Зайди на https://my.telegram.org/apps
2. Создай application — получишь `api_id` и `api_hash`
3. Положи в `.env`:
   ```
   TG_API_ID=12345678
   TG_API_HASH=abcdef...
   ```

### 2. Groq (рекомендуется)
1. Зарегайся на https://console.groq.com
2. Создай API key (бесплатный)
3. Положи в `.env`: `GROQ_API_KEYS=gsk_...` (через запятую можно несколько)

> Можно добавлять ключи прямо из веб-панели, .env нужен только для удобства.

### 3. Прокси (опционально, но рекомендуется)
Groq работает из РФ напрямую обычно, но при банах помогают прокси.
Формат: `socks5://user:pass@host:port` или `http://...`
Можно добавить в `.env` через запятую (`AI_PROXIES=...`) или из панели.

### 4. Пароль панели
```
WEB_PASSWORD=поставь_свой
```

## Запуск

```bash
source .venv/bin/activate
python -m app.main
```

Открой http://127.0.0.1:8800, введи пароль из `.env`.

## Первый запуск

1. **Вкладка Telegram** → введи телефон → получи код → войди (2FA если есть)
2. **Каналы** → нажми «Синхронизировать с TG» → отметь нужные галочками
3. **AI ключи** → проверь что Groq добавлен (или добавь руками)
4. **Персона** → проверь промпт (по умолчанию заточен под школу программирования)
5. **Дашборд** → нажми «▶ Запустить»

С этого момента софт мониторит новые посты в активных каналах и через 3–30 мин (настраивается в `.env`) генерит и отправляет комменты.

## Безопасность

- ⚠ **Не оставляй панель доступной из интернета без HTTPS и нормальной авторизации.** По умолчанию слушает только `127.0.0.1`.
- ⚠ Telegram может банить за массовый спам в комментах. Используй умеренно: `MAX_COMMENTS_PER_HOUR=8` по умолчанию.
- ⚠ Сессия Telethon лежит в `app/data/sessions/` — это эквивалент логина. Не делись файлом.

## Файлы

```
app/
  main.py            — FastAPI entry + lifespan
  config.py          — .env settings (pydantic-settings)
  db.py / models.py  — SQLite + SQLAlchemy async
  worker.py          — слушатель постов + диспетчер отложенных коммов
  tg/
    client.py        — Telethon клиент + логин flow
    dialogs.py       — список каналов
    commenter.py     — отправка комментов в обсуждения
  ai/
    providers.py     — Groq/OpenRouter/Cerebras/SambaNova/Mistral
    router.py        — ротация провайдеров
    prompts.py       — сборка system+user промпта
  proxies/pool.py    — пул прокси с авто-фейловером
  api/routes.py      — REST API для панели
  api/auth.py        — простая cookie-авторизация
  static/            — index.html, login.html, app.js, style.css
  data/              — SQLite + сессии Telethon
```

## Лицензия

Используй на свой страх и риск. Соблюдай ToS Telegram и провайдеров.
